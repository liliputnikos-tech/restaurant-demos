# Restaurant demo sites

One-page demo websites prepared for independent cafés and restaurants in Acton, Shepherd’s Bush and White City, London.

Live: https://liliputnikos-tech.github.io/restaurant-demos/

These are demos, not the official websites of the businesses shown. Pages carry a `noindex` tag so they stay out of search results.

## Layout

- `index.html`: overview linking every demo
- `<slug>/index.html`, `style.css`, `favicon.svg`: one static site per folder, no build step
- `<slug>/img/`, `<slug>/fonts/`: photos and self-hosted fonts, generated by `tools/build_assets.py` from the sources in `assets.json` (run by the `assets` GitHub Actions workflow)

Photos are illustrative, from Wikimedia Commons (CC0) and Unsplash (Unsplash License). Fonts are from Google Fonts (SIL Open Font License).
